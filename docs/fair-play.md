# 경기 화면 이탈 감지

- 선수 입장으로 참여하는 일반판/지하철판(게스트 포함)에 기본 적용한다.
- 자유 연습, 결투, 형성평가는 이번 변경 범위가 아니다.
- 입장 버튼의 사용자 동작으로 Fullscreen API를 호출한다. 지원되지 않거나 거절되면 입장을 진행하지 않는다.
- 대기 중에는 안내만 표시한다. 경기 시작 후 blur, hidden, fullscreen 해제 중 하나가 발생하면 입력 화면을 제거한다. 지하철 암기 시간도 포함한다.
- 정상 종료 후에는 감지 이벤트를 해제한다.
- typing_scores의 screenExitDetected, screenExitReason, screenExitAt 필드에 서버가 중단을 기록한다. 기존 컬렉션 경로는 유지한다.
- 이탈 보고는 소유권 확인 트랜잭션으로 처리한다. 평소 감지에는 DB 접근이 없다. 최초 보고는 통상 점수 문서 1 read/1 update이며 트랜잭션 재시도나 기존 구독 수신에는 추가 비용이 발생할 수 있다.
- 중단된 기록은 게임 종료 보상, 순위 보상, 새 명예의 전당 집계에서 제외한다. 기존 저장형 명예의 전당 결과는 자동 수정하지 않는다.
- 교사 점수판에는 화면 이탈 표시와 마지막 저장된 점수가 남는다. 미동기화 입력을 추가 저장하지 않는다.
- 로컬 중단 표식은 재입장 시 재전송한다. 서버 중단 표식은 재입장으로 지워지지 않는다. 자동 재시도/폴링은 하지 않는다.

## 배포

교사 점수판의 재입장 허용은 교사 UID를 서버에서 확인하고 진행 중인 방에서만 허용한다. 점수/진행/시간은 변경하지 않고 screenExitRevision을 증가시킨다. 학생은 홈에서 같은 방에 다시 입장하며 서버 revision보다 오래된 로컬 중단 표식은 지운다. 이전 시도의 지연 보고는 서버가 무시한다. 학생 브라우저는 이 기능을 지원하는 최신 버전으로 새로고침해야 한다.

웹/API 배포와 함께 firestore.rules도 배포해야 일반판의 중단 이후 직접 점수 수정을 서버에서 거절한다. 지하철 제출 API는 자체적으로 중단 표식을 검사한다. Rules 배포 없이 완전 적용된 것으로 간주하지 않는다.

## 한계

실제 부정행위가 아니라 화면 이탈 사실을 기록한다. 주소창/시스템 대화상자도 blur를 발생시킬 수 있다. Alt+Tab 자체를 막지는 않는다. 변조된 클라이언트나 오프라인 상태에서 보고되지 않은 이탈은 서버가 스스로 판별할 수 없다. 크롬북 실기기의 전체 화면/한글 입력 동작을 수업 전 확인해야 한다.
